How it works

The agent is a Double-DQN with a fully convolutional network: five 3×3 conv layers that output one Q-value per cell, and the highest value among unopened cells is its move. It saw only 9×9 boards while training, and it reads the board as numbers and unopened squares, never flags.

On 9×9 with 10 mines it wins 86.6% of games, against 68.1% for a hand-written deduction solver. The same 9×9 weights on a 16×16 board with 40 mines, which they never trained on, win 56.6% against the solver's 36.7% (10,000 fixed-seed games each). Some positions are real guesses, so no agent wins every game.

For boards larger than 9×9 this page loads a second network: the 9×9 model fine-tuned on 16×16 boards with 40 mines. It wins 68.5% of 16×16 games on 10,000 unseen seeds (a fresh 3,000-game check gave 69.2%; the solver wins 36.1%). That is the best of four training runs, so a typical run would land a few points lower. Smaller boards keep the 9×9 model.

The network was exported to ONNX and runs here with onnxruntime-web (WebAssembly). The game logic is a JavaScript port of the Python environment, checked against it by tests. Code, training notes and results: github.com/apih99/MineSweeperAI.

Seeds are for this page's JavaScript random generator and do not reproduce the Python boards.
